☁️ 雲端同步（GitHub Gist）

用你自己的 GitHub 帳號當作雲端硬碟，跨裝置同步。第一次設定：到 github.com/settings/tokens 建立一個 Personal Access Token（勾選 gist 權限就好），貼在下面。第一台裝置留空「Gist ID」；設定完成後，把產生出來的 Gist ID 複製到你其他裝置，貼進同一個欄位，就能連到同一份雲端資料。
